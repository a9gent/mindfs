# 四组功能迭代方案（已按用户指示：子代理审查方案 → 执行 → 子代理审查+测试验收）

## 调研结论（关键代码事实）

- **跨项目发消息可行且零后端改动**：会话懒创建 —— 首条消息走 WS `session.message`，`session_key` 为空时后端 `CreateSession(RootID)`（`server/internal/api/ws.go:600-630`）。前端 `handleSendMessage`（App.tsx:6399）和 `sessionService.sendMessage`（session.ts:921）都接受任意 `rootId`，只是 UI 写死了 `currentRootIdRef.current`。`managedRootByIdRef`（App.tsx:2456）持有全部已添加项目。
- **接力包现状**：`HandoffPackDialog`（复制/存模板/插入），「插入」经 `editDraftRequest` 通道 append 到当前会话输入框（App.tsx:2555）。
- **文件重命名**：已有 `POST /api/file/operation {action:"rename"}`，UI 只有 `window.prompt`（FileOperations.tsx:50）；FileViewer 头部（:304）无内联改名。绝对路径 = `managedRootByIdRef[rootId].root_path + "/" + file.path`；复制用 `copyText`（clipboard.ts:71）。
- **蓝环**：`BlueRingAction` union/options/labelKeys（quickSwitch.ts:37-160），runAction switch（SessionQuickActions.tsx:142），FileTree 设置页自动遍历新动作。
- **时间筛选**：1h/3h/1天是筛选 chips（SessionFilterBar.tsx），非分组标题；置顶只在自己项目组内排序（sessionListMerge.ts:59），无跨项目置顶专区。
- **最近文件数据源**：树条目带 `mtime`（directorySort.ts:8）；git status（git.ts:102）；会话关联文件 `session.related_files`（session.ts:1369）。
- **输入框高度**：`TokenEditor`（components/editor/TokenEditor.tsx）contentEditable 自动增高，硬上限 `maxHeight: 240px`（:877）；已有 `fillHeight` 不限高模式（:875-877）。容器 `minHeight: 44px`（ActionBar.tsx:1334/1602）。

## A. 接力包 → 其他项目新会话 + 文件改名/复制路径 + 蓝环绑定

### A1. 接力包「新建会话到其他项目」
- `HandoffPackDialog` 顶部加「目标会话」选择区：默认 = 当前会话（现有行为）；可选其他项目（`managedRoots` 排除当前 root），选中后出现可选「新会话名称」输入。
- 确认逻辑：选了其他项目 → 切换项目 → 新建会话 → 接力包**预填**输入框（走 `editDraftRequest`，不自动发送）→ 关闭并提示。未选 → 走现有 onInsert。
- 新增 props `onNewSessionInProject(rootId, name?, pack?)`，App.tsx 实现。
- i18n：`handoff.targetSession/targetCurrent/targetOtherProject/targetNamePlaceholder/openInNewSessionHint` 等（zh+en）。

### A2. 文件头部：点击文件名内联改名 + 复制绝对路径
- `FileViewer` 头部文件名（:304）对齐 SessionViewer 顶部改名交互：点击变 `<input>`（IME 守卫、Enter 提交、Escape/blur 取消）→ `POST /api/file/operation {action:"rename"}` → 成功后用新路径重开文件 + `refreshTreeDir`。
- 文件名旁加「复制路径」按钮：拼绝对路径 → `copyText` → 1.5s「已复制」反馈。
- 树内右键 prompt 改名保留；i18n `file.renameInline/copyFullPath/copied/renameFailed`（zh+en）。

### A3. 蓝环新增可绑定动作（3 个）
- `quickSwitch.ts`：union + options 追加 `renameCurrentFile`、`copyCurrentFilePath`、`copySessionHandoff`，默认均 `none`。
- `SessionQuickActions.tsx` props + runAction 三个 case；`ActionBar.tsx` 透传；App.tsx 接线（rename/copyPath/copyHandoff 各自 handler + toast）。

## B. 会话列表剃刀 + 置顶专区

### B1. 筛选 chips 精简（4→2）
- `SessionFilterBar.tsx`：全部/近1小时/近3小时/近1天 合并为 1 个循环 chip（点击依次切换，label 显示当前值）；「运行中」chip 保留。`sessionFilter.ts` 逻辑不动。

### B2. 跨项目「已置顶」专区（仅多项目列表）
- `SessionList.tsx` 多项目分支顶部新增「已置顶」专区（复用 runningSection 头部样式）：汇总所有项目置顶会话，条目带项目名小标签；空则不渲染。组内不再重复显示置顶会话，计数微调。单项目列表维持现状。

## C. 快捷切换卡片「最近文件」分区

- `SessionQuickActions` 卡片顶部新增「最近文件」分区：当前 root 当前目录下按 `mtime` 取最近 3-5 个文本类文件，点击直接打开；命中 `related_files` 或 git status 修改时加「本会话修改」标记；可折叠（localStorage），无内容隐藏。

## D. 输入框高度可自定义（拖拽调节）

- **TokenEditor** 加 `maxHeightOverride?: number`：非空时替代默认 240px（fillHeight 优先级不变）。
- **ActionBar**：`composerMaxHeight` 状态（初始 240，localStorage `mindfs-composer-max-height`，钳制 [44, min(70vh, 560)]）；`message-input` 顶边加拖拽热区（hover 显示小横条握把），Pointer Events 拖拽实时改高度（上拖变高），双击重置默认；传给 TokenEditor。移动端 touch 同样支持。
- i18n：`action.composerResizeHint`（zh+en）。
