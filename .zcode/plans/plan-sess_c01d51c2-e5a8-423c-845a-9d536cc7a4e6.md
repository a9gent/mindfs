# 完整方案 v3（先修 bug → 列表重构 → 看板改名 → 移动端模板切滑 → 蓝环修复 + 新手势）

## 调研结论（关键事实，均已核对 file:line）

- **平铺/多项目空列表根因**：SessionList.tsx flatMode 渲染分支（~1570）位于 `loading && groups.length===0`（~1635）判断之前——加载中直接渲染"空"文案；且 `fetchMultiRootSessions`（session.ts:1231-1237）在 `api_not_ready`（E2EE 通道未就绪）时静默返回 `[]`，App `loadMultiProjectSessionGroups`（5268-5323）同样吞错 → 侧栏看起来空无一物。非平铺模式同样受静默吞错影响（用户报告 1）。
- **平铺置顶混排**：flatRows（982-1000）过滤掉 pinned_at，pinned 专区（1572-1605）独立渲染但不随 sortAsc 独立排序；普通区无项目分组。
- **组头无折叠按钮**：折叠只能靠组底部 ToggleRowButton（1880-1905），且仅 `totalCount>6` 时出现；组头（1741-1823）只有项目名+置顶钮。expandedProjects 持久化键 `mindfs-session-projects-expanded`（line 83）。
- **全局搜索失败根因**：GlobalSearchDialog.tsx:126-146 直接调 `searchSessions(..., {rethrow:true})`，`protectedJSON`（api.ts:27-37）在 E2EE 未就绪时抛 `api_not_ready`、401/503 抛 ProtectedAPIError → catch 置 failed → "搜索失败"。App 内搜索有门控，对话框没有。
- **手势设置打不开根因**：链路完整（SessionQuickActions:224 → ActionBar:2006 → App:3223 setOpenBlueRingSettingsRequest → FileTree:2731 effect → openBlueRingSettings），但蓝环设置 popover 是 sidebar 容器内 position:absolute（FileTree.tsx:4672-4688）；手机端 sidebar 关闭/未挂载时 popover 渲染在不可见容器里 → 看不到。
- **openNodesPage**：App.tsx:3220 直接 `window.location.assign(ownNodePageURL())`；NodePickerCard.tsx 已存在但**完全未被使用**（自带 load/empty/escape，自取 /api/nodes，点行 `nodeDestinationURL`）。
- **手势词汇**：tap/doubleTap + 单笔 up/left/right/upLeft/upRight + 两段（up 首段）组合 7 种；classifyRingPath fallback（quickSwitch.ts:374-388）对"向下"返回 null；两段机制仅支持 up 首段（classifyUpSegment:295）。动作 31 个（quickSwitch.ts:37-68），默认全 none 除 tap/up=quickSwitch、left=newSession。设置 UI 遍历 BLUE_RING_GESTURES 自动渲染。
- **看板改名**：AddToKanbanDialog.tsx:103-113 创建任务（input=当前会话名）→ attach → 强制 rename 为 `{模板名} / {原名}`，用户无机会自定义。任务 TaskPatch 无 Name 字段，input 无长度校验；rename API `POST /api/sessions/{key}/rename?root=`。
- **看板模板切换**：tab 条（App.tsx:13320-13422）onClick only；阶段列横向滚动容器（13684-13693）overflowX:auto 无 touch 处理；已有 `cycleKanbanTemplate`（3187-3204）和 edgeSwipe.ts 分类助手（classifySwipeIntent/swipeProgress/swipeRelease）。
- i18n：zh-CN.ts / en-US.ts 平铺点键，两边都要加。

## A. 修 bug（最优先）
1. **列表空/加载态**：flatMode 分支先判 `loading && groups.length===0` 显示加载态；`loadMultiProjectSessionGroups`（当前无 catch，App.tsx:5268）加 catch + `MultiProjectSessionList` 新增 `error` prop（仿 ExternalSessionList），真实错误显示"加载失败 + 重试"；api_not_ready 显示"等待加密通道…"。
2. **全局搜索**：App 用已有 `bootstrapState` 订阅传 `apiReady` prop 给 GlobalSearchDialog，进搜索 effect deps；未就绪显示等待态（不轮询）；`api_not_ready`→等待，`ProtectedAPIError`→错误+重试按钮（区分两态）。
3. **手势设置**：蓝环设置 popover 移入 createPortal(document.body) fixed 卡片；手势路径无锚点 → 移动端居中底部 sheet 风格、桌面居中；sidebar 内齿轮入口正常锚定。sidebar fallback 用真实 state 名（grep 确认，如 setIsLeftOpen）。
4. **节点页**：`handleOpenNodesPage` 改为打开 NodePickerCard；该卡加 `apiReady` 门控，`api_not_ready` 映射 i18n 文案而非裸字符串。

## B. 列表重构（需求 1-3）
1. **平铺模式两区**：上方"已置顶"专区（跨项目、按 sortAsc 独立排序），下方按项目分组的普通会话区——每项目一个组头（项目名 + 计数 + 折叠箭头），组内会话按 sortAsc 排序（组序按组内最新 updated_at）。
2. **非平铺多项目**：组头右侧加折叠/展开箭头按钮（所有组，不只 >6 的组）；保留底部 ToggleRowButton 展开更多。
3. expandedProjects 沿用（默认折叠）；平铺模式组折叠生效，且组头同时提供"展开更多/remaining"行（复用 handleProjectToggle + onLoadMoreProject），否则平铺无法加载每组 6 条之外。
4. 正序/倒序（sortAsc）同时作用于置顶区与各项目组（仅排序已加载窗口，不触发重取——明确接受）。
5. 平铺分组须保留"已置顶父会话的子会话"在组内（复用 grouped 模式的 unpinnedSessions 重建管线），不得丢失或双渲染。

## C. 添加到看板：自定义名称（需求 4）
AddToKanbanDialog 底部加可选输入框，默认值 = 当前会话名（按已加载的模板名逐一匹配 `startsWith("{模板名} / ")` 剥前缀，不用正则），可编辑；提交时 task input 与 rename 均用该值（rename 仍为 `{模板名} / {自定义名}`）；留空 = 默认。最终名通过 onAttached 传出并走 bumpCacheVersion 路径，防止列表回显旧名。i18n 两 locale。

## D. 移动端看板：边界滑动切模板（需求 5）
1. 阶段列横向滚动容器（仅该容器，勿挂 tab 条）加 touch 手势：passive touchstart/touchmove/touchend（绝不 preventDefault、不改 touch-action，保住原生滚动）；用 touchstart 时 scrollLeft 快照判边界。方向映射：左边界(scrollLeft<=0) 手指右移(dx>0)=上一模板；右边界(dx<0)=下一模板；垂直主导或双指忽略（复用 edgeSwipe.classifySwipeIntent）；10px 越界阈值；拖动中 tab 条对应项高亮。
2. 容器无溢出（scrollWidth===clientWidth）时两向均可切（纯按手指方向）。prev/next 顺序抽成共享 helper（[ALL, ...模板id]，与 cycleKanbanTemplate 同源防漂移）。

## E. 蓝环新手势（需求 7/8）
新增 4 个手势（默认 none）：`down`、`downLeft`、`downRight`（扩展 classifyRingPath fallback 对角带判定）、`upLeftThenDown`（mapTwoStageGesture 补 upLeft+down 映射）。**upLeftThenDown 必须同时加入 BLUE_RING_PATH_GESTURES**，否则拖动中提示条会消失。设置 UI 为文本标签（无图标），补 4 条 BLUE_RING_GESTURE_LABEL_KEYS + 双 locale 键。向下短上腿(<40px)时按既有降级规则落回单笔分类（测试用 ≥40px 腿）。normalize 兼容旧存储，无迁移风险。
