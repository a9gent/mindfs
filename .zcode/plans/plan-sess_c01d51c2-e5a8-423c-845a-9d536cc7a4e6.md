### C2. 新建面板组件
**新文件：`web/src/components/QuickSaveFilePanel.tsx`**（createPortal 弹层，样式参考 `BottomSheet`/现有 dialog，手机底部弹出、桌面居中）

Props：`{ open: boolean; rootId: string | null; currentDir: string; onClose: () => void; onSaved: (path: string, dir: string) => void; }`

内容自上而下：
1. **文件名**：单行输入，默认值如 `untitled.md`；拆成"主名 + 后缀"两段（后缀默认 `.md`，可编辑）。无后缀时按 `.md` 补齐。
2. **内容框**：多行 textarea，可留空；右上角"从剪切板粘贴"按钮，调用新增的 `readClipboardText()`。
3. **目标目录选择器**：
   - 默认 = 当前目录（`currentDir`，展示为相对根路径）；
   - 列出当前目录下的子目录（`/api/tree?root&dir=` 过滤 `is_dir`），可逐级进入；
   - "上一级"返回；
   - 可手动输入相对子路径（如 `docs/specs`）；
   - 最近目录（`services/recentDirs.ts` 的 `listRecentDirs()` 过滤同 `rootId`）一键跳转；
   - 所有路径限制在项目根内（`/api/tree` 已按 root 解析，越界自然失败）。
4. **底部按钮**：取消 / 保存。

**保存流程**（复用现有 API，无服务端改动）：
1. `POST /api/file?root=ROOT` body `{dir, name}` → 得 `{path}`；
2. 若内容非空：`fetchEditableFile(root, path)` 取 `revision` → `saveTextFile(root, path, content, revision)`（`services/file.ts:694/699`）；
3. `onSaved(path, dir)` → App 里 `refreshTreeDir(root, dir, ...)` 刷新树；空内容时顺带 `actionHandlers.open({path, root})` 打开该文件继续编辑；有内容则只提示保存成功；
4. 错误处理：409 → `directory.fileExists`；非法名 → `directory.invalidFileName`；其它 → `directory.createFileFailed`。

**剪切板读取**：在 `web/src/services/clipboard.ts` 新增 `export async function readClipboardText(): Promise<string>`，移植 `TokenEditor.tsx:395–410` 的 Capacitor `Clipboard.read` → `navigator.clipboard.readText` 回退逻辑。
